# 06 — Repository 생성

## 개요

원작자가 자신의 세계관·IP를 등록하는 폼 페이지. 제출 후 Repository 상세 페이지로 이동한다.

---

## 접근 권한

🔑 로그인 사용자 (생성한 사람이 자동으로 원작자가 됨)

---

## 화면 구성요소

### 기본 정보 섹션
- 제목 입력 (필수, 최대 100자)
- 설명 입력 (선택, 최대 500자)
- 썸네일 이미지 업로드 (선택)
- 태그 입력 (자동완성 지원, 최대 10개)
- 외부 링크 입력 (선택, 최대 3개)

### README 섹션
- 작품 설명 (마크다운 에디터)
- 주요 캐릭터 목록 (이름 + 설명, 동적 추가/삭제)
- 주요 지역·장소 목록 (동적 추가/삭제)
- 핵심 세계관 규칙 목록 (동적 추가/삭제)
- 금지 설정 목록 (동적 추가/삭제)

### 모집 설정 섹션
- 모집 중인 기여 영역 (체크박스 멀티 선택)
  - 캐릭터 추가 / 캐릭터 수정
  - 세계관 설정 추가
  - 지역·장소 설정
  - 사건·에피소드 제안
  - 아이템·능력·규칙 제안
  - 관계 설정
  - 대사·문체·분위기 제안
  - 기타
- 기여 가이드라인 입력 (마크다운 에디터)

### 제출 버튼
- "Repository 만들기"
- "임시 저장" (선택 — MVP에서는 구현 후순위)

---

## 사용자 액션

| 액션 | 결과 |
|------|------|
| 태그 입력 | 자동완성 드롭다운 표시 |
| 캐릭터 추가 버튼 | 캐릭터 입력 행 추가 |
| 캐릭터 삭제 버튼 | 해당 행 제거 |
| 모집 영역 체크박스 | 선택/해제 |
| Repository 만들기 | 유효성 검사 → API 호출 → 생성 |

## API 연동

### POST /api/v1/repositories
```
Header: Authorization: Bearer {access_token}

Request:
{
  "title": "내 판타지 세계관",
  "description": "마법이 존재하는 세계의 이야기",
  "thumbnail": "https://...",
  "tags": ["판타지", "마법"],
  "external_links": ["https://..."],
  "readme": {
    "content": "## 세계관 소개\n...",
    "characters": [
      { "name": "아르카", "description": "주인공 마법사" }
    ],
    "regions": [
      { "name": "에테르 왕국", "description": "마법이 가장 발달한 나라" }
    ],

  "id": 1,

  ...
}
```

### GET /api/v1/tags?q={keyword}
태그 자동완성.

## 상태 처리

| 상태 | 처리 |
|------|------|
| 제목 미입력 | "제목을 입력해주세요" 인라인 에러 |
| 제목 초과 | "제목은 100자 이하여야 합니다" |
| 태그 10개 초과 | "태그는 최대 10개까지 입력 가능합니다" |
| 네트워크 오류 | "저장에 실패했습니다. 다시 시도해주세요" |

---

## 규칙 및 제약

- 제목은 필수 입력
- README 내 캐릭터·지역·규칙·금지 설정은 최소 입력 강제 없음 (선택)
- 생성 후 원작자는 수정 페이지에서 언제든 변경 가능
- 생성한 사람이 자동으로 `author`로 등록됨

---

## 연결 화면

- 생성 성공 → Repository 상세 (`/repositories/{repo_id}`)
- 취소 → 이전 페이지 또는 `/repositories`
